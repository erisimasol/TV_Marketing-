<h2>🔎 Types of Regression</h2>
<p>
  <img src="https://img.icons8.com/external-flaticons-lineal-color-flat-icons/64/000000/external-linear-data-science-flaticons-lineal-color-flat-icons.png" alt="Linear Regression Icon"/>
</p>
<ul>
  <li><b>Linear Regression</b> → Straight-line relationship between variables</li>
  <li><b>Non-Linear Regression</b> → Curved or complex relationships</li>
  <li><b>Polynomial Regression</b> → Captures non-linear patterns using polynomial terms</li>
</ul>

<h2>📊 Performance Metrics</h2>
<table>
  <tr><th>Metric</th><th>Description</th><th>Interpretation</th></tr>
  <tr><td>MSE</td><td>Mean Squared Error</td><td>Lower is better</td></tr>
  <tr><td>RMSE</td><td>Root Mean Squared Error</td><td>Same units as target variable</td></tr>
  <tr><td>MAE</td><td>Mean Absolute Error</td><td>Less sensitive to outliers</td></tr>
  <tr><td>R²</td><td>Coefficient of Determination</td><td>Closer to 1 = better fit</td></tr>
</table>

---

<h2>🛠 Regularization Techniques</h2>
<ul>
  <li><b>Lasso Regression</b> → Shrinks coefficients, feature selection</li>
  <li><b>Ridge Regression</b> → Penalizes large coefficients</li>
  <li><b>ElasticNet</b> → Combines Lasso & Ridge</li>
</ul>
